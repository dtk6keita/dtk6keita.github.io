DTK6 Fire Stick対応 ブラッシュアップ版V8 DEMOモード付き

【通常運用】
公開URLをそのまま開きます。
例：https://dtk6keita.github.io/

【DEMOモード】
URLの最後に ?demo=1 を付けて開きます。
例：https://dtk6keita.github.io/?demo=1

初期時刻と進行速度も指定できます。
例：https://dtk6keita.github.io/?demo=1&time=17:04:50&speed=30

・time：DEMO開始時刻
・speed：進行倍率。30なら実時間1秒で画面内30秒進みます。
・DEMO中はヘッダーに赤い「DEMO ×30」表示が出ます。

PC確認時の操作：
・Dキー：DEMOモード ON/OFF
・Rキー：DEMO開始時刻にリセット

通常運用へ戻す：
URLの ?demo=1 以降を削除して再読み込みしてください。

【GitHub Pagesへのアップロード】
このZIPを解凍し、中身をリポジトリ直下へアップロードしてください。
ZIPそのものはアップロードしません。
リポジトリ直下に index.html が見える状態にします。
Settings → Pages → Deploy from a branch → main / root
