DTK6 DIS V15

変更点
1. ポスター切替時の「POSTER」「画像を読み込み中」などのタイトル/プレースホルダー画面を完全削除。
2. CHECK-INはOFFERの15分前から表示。例：17:15 OFFER → 17:00 CHECK-IN。
3. Android TV/ストリーミング端末向けに、実際のHTML5動画をループ再生して画面スリープ/スクリーンセーバー移行を抑止。
4. 対応ブラウザでWake Lock APIも併用。

重要
端末OS側のスクリーンセーバー設定そのものをWebページから100%無効化することはできません。
運用端末ではAndroid TV側の「スクリーンセーバー」「省電力」「画面消灯」もOFF/最長に設定してください。
